# SmartCampus

Ứng dụng Expo React Native minh họa màn hình hồ sơ sinh viên và các trạng thái của `Pressable`.

## Component chính

- `SmartCampusScreen`: quản lý màn hình và tab đang chọn.
- `ProfileScreen`: hiển thị hồ sơ, tìm kiếm và nút Lưu.
- `EditProfileModal`: chỉnh sửa thông tin sinh viên.
- `WaitingScreen`: nội dung chờ thiết lập cho Trang chủ, Thông báo và Cài đặt.
- `BottomNav`: thanh điều hướng phía dưới.

## Cách chạy

```bash
npm install
npm start
```

Sau đó quét mã QR bằng Expo Go hoặc nhấn `a` để chạy Android, `w` để chạy trên web.
